=============================================
SITE WEB ESPACE MAMPIHANTA - ANT SIRABE
=============================================

Site web officiel pour Espace Mampihanta, prestataire événementiel à Antsirabe.

STRUCTURE DES FICHIERS :
------------------------
- index.html : Page d'accueil principale
- /css/style.css : Tous les styles du site
- /js/script.js : Fonctions JavaScript interactives
- /images/ : Dossier pour toutes les images
  - /images/logo/ : Logo de l'entreprise
  - /images/accueil/ : Images de bannière
  - /images/services/ : Photos des services
  - /images/galerie/ : Galerie d'événements
  - /images/icones/ : Favicon et icônes

FICHIERS DE CONFIGURATION :
---------------------------
- robots.txt : Pour les moteurs de recherche
- sitemap.xml : Plan du site pour SEO
- .htaccess : Optimisation serveur Apache

COMMENT UTILISER :
------------------
1. Téléversez tous ces fichiers sur votre serveur web
2. Remplacez les images factices par vos vraies photos
3. Mettez à jour les coordonnées dans index.html
4. Testez le site sur différents navigateurs
